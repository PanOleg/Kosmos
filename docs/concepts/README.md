## Локальні копії

Знімки тих самих зображень, щоб їх можна було відкрити без доступу до Canva:

- `map.jpg`: карта станції «Горизонт»
- `classes.jpg`: чотири класи
- `enemies.jpg`: дванадцять типів ворогів і боси
- `hud.jpg`: екран гри з інтерфейсом
- `controller.jpg`: пульт на телефоні

Це орієнтири для палітри й силуетів, а не точні макети. На `hud.jpg` четвертий гравець підписаний «Sniper», це помилка генератора: має бути Технік.
