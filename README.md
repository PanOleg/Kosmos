# Горизонт

Кооперативний шутер з видом згори для 1–4 гравців на спільному екрані; телефони — пульти.
Документи: `docs/` (рішення — `docs/DECISIONS.md`, концепти — `docs/concepts/`).

```sh
pnpm install
pnpm dev          # екран http://localhost:5173 + пульт https://<LAN-IP>:5174/controller/
pnpm test         # vitest: симуляція, протокол, лобі
pnpm lint && pnpm typecheck
```

## Як грати

1. Відкрийте екран на ноутбуці чи телевізорі. Ноутбук і телефони мають бути в одній мережі Wi-Fi.
2. Відскануйте QR телефоном. Сертифікат пульта самопідписаний: один раз підтвердьте «Перейти на сайт».
   HTTPS потрібен, щоб екран телефона не гас (Wake Lock).
3. Оберіть клас (класи в матчі унікальні), натисніть «Готовий». Коли всі готові — відлік і старт.

Пульт: ліва половина — стік (з'являється під пальцем), різкий рух пальцем — ривок;
права половина — здібність. Сторінку можна оновити або заблокувати телефон: пульт повернеться
у свій слот. Без зв'язку понад 5 с гравцем керує бот.

Клавіатура на екрані (лобі): Пробіл — приєднатися (WASD, другий — стрілки), Q/E — клас,
B — бот, Backspace — прибрати, Enter — старт / з результатів до лобі.

## Розробка

- `?quick&bots=N` — одразу матч: клавіатура + N ботів.
- `?net=local` — без інтернету: пульти відкриваються в інших вкладках з адреси в QR (BroadcastChannel).
- `?debug` — fps, draw calls, затримка кожного пульта; `window.game`; клавіші 1/2 спавнять ворогів.
- `?seed=N` — сід матчу.
- `VITE_CONTROLLER_URL` — адреса пульта в QR замість автовизначеної; `CONTROLLER_HTTP=1` — пульт без TLS.
