# Горизонт

Кооперативний шутер з видом згори для 1–4 гравців на спільному екрані; телефони — пульти.
Документи: `docs/` (рішення — `docs/DECISIONS.md`, концепти — `docs/concepts/`).

```sh
pnpm install
pnpm dev          # екран http://localhost:5173 + пульт https://<LAN-IP>:5174/controller/
pnpm test         # vitest: симуляція, протокол, лобі
pnpm lint && pnpm typecheck
```

## Як грати

1. Відкрийте екран на ноутбуці чи телевізорі. Ноутбук і телефони мають бути в одній мережі Wi-Fi.
2. Відскануйте QR телефоном. Сертифікат пульта самопідписаний: один раз підтвердьте «Перейти на сайт».
   HTTPS потрібен, щоб екран телефона не гас (Wake Lock).
3. Оберіть клас (класи в матчі унікальні), натисніть «Готовий». Коли всі готові — відлік і старт.

Пульт: ліва половина — стік (з'являється під пальцем), різкий рух пальцем — ривок;
права половина — здібність; між хвилями вона стає трьома кнопками покращень, аптечка — кнопка зверху. Сторінку можна оновити або заблокувати телефон: пульт повернеться
у свій слот. Без зв'язку понад 5 с гравцем керує бот; на інших пультах є кнопка «Чекати» — тоді матч чекає його на паузі.
Пауза з пульта — утримати ⏸ у верхній смужці пів секунди.

Клавіатура в матчі: WASD — рух, Пробіл — ривок, Shift — здібність, 1–4 — покупки між хвилями (зброя, броня, здібність, аптечка), Esc / P — пауза;
другий гравець: стрілки, Enter, правий Shift, Numpad 1–4.
У лобі: Пробіл — приєднатися (WASD, другий — стрілки), Q/E — клас, C — забарвлення,
B — бот, Backspace — прибрати, Enter — старт / з результатів до лобі (або «Ще раз» на пульті, або само за 60 с).

## Розробка

- `?quick&bots=N` — одразу матч: клавіатура + N ботів.
- `?net=local` — без інтернету: пульти відкриваються в інших вкладках з адреси в QR (BroadcastChannel).
- `?debug` — fps, draw calls, затримка кожного пульта; `window.game`; F1/F2 спавнять ворогів.
- `?seed=N` — сід матчу.
- `VITE_CONTROLLER_URL` — адреса пульта в QR замість автовизначеної; `CONTROLLER_HTTP=1` — пульт без TLS.

## Розміщення (Vercel)

`vercel.json` уже налаштований: збірка `pnpm build:web`, сайт — `packages/screen/dist` (пульт у `/controller/`).
Змінна середовища `VITE_TURN_URL` = `https://<app>.metered.live/api/v1/turn/credentials?apiKey=<ключ>`
(безкоштовний TURN від Metered) — щоб телефони з'єднувалися в будь-якій мережі. Після зміни змінної — перезібрати.
