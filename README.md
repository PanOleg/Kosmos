# Горизонт

Кооперативний шутер з видом згори для 1–4 гравців на спільному екрані. Документи: `docs/`.

```sh
pnpm install
pnpm dev          # екран: http://localhost:5173
pnpm test         # vitest: детермінізм, колізії, бій, Стрілець, хвилі
pnpm lint && pnpm typecheck
```

Керування (поки без телефонів): WASD — рух, Пробіл — ривок, стрільба автоматична. R — новий матч після результатів.

Параметри URL для розробки: `?p2` (другий гравець на стрілках, Enter — ривок), `?bots=N`, `?seed=N`,
`?debug` (fps і draw calls, F3; `window.game`; клавіші 1/2 спавнять Скаутів/Стрільців).
